# memocore-bancada-e5

Repositorio de bancada descartavel da Etapa 5.1 (cupom 61, MemoCore): prova de publicacao de um Cloudflare Container com a imagem candidata dos extratores (`Dockerfile.extratores`) num Worker de bancada (`memocore-bancada-e5`), fora do Worker de producao. Deploy via Workers Builds (Rota A).
